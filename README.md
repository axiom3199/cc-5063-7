# 测点曲面拟合工作台 · 设计观测制作

翼尖样件的参数化曲面拟合工作台，包含两个模式：

- **测点拟合工作台** — 从测点文件完成参数标签校验、漂移/折线假设裁决、拟合与发布门控。
- **设计观测制作** — 自制带参数标签与可靠度的测点，保存真值与观测生成脚本，用独立样板
  （装配者）与测点拟合（拟合者）两个角色的分离来验证重建，并把"补测还是复核方法"的判断
  落到执行证据上。

## 界面启动

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5173/>，点击右上角 **「设计观测制作」** 标签进入制作工作台。

在生产构建下：

```bash
npm run build
npm run preview
```

## 设计观测制作工作台能做什么

进入「设计观测制作」后：

1. **选择资料包**（左上「资料包」下拉）。四个已入库资料包覆盖两个设计轴：
   - 真值成型方法：`analytic`（解析真值直接求值）vs `section`（标定截面拼装后插值）；
   - 采样表：`A`（尖棱处稀疏，峰顶落在两排之间）vs `B`（仅在尖棱附近加密，含峰顶排）。
2. **查看约定检查**（左中「约定检查」）：拟合残差、参数域覆盖、样板扣合率、尖棱带测点数、
   丢失特征、棱边补测建议、成型方法标注 —— 全部由本次拟合实际算出，不做断言。
3. **查看棱边补测建议**（左下）：样板逐段扣合率最低的棱边分段，以及应"补测"还是"复核方法"。
4. **中间视口**显示拟合曲面，按每个测点到重建曲面的距离着色（蓝近→红远）；橙色带为尖棱监测带。
   点击曲面可在右侧查看局部测点残差。
5. **右侧「拟合核控件」** 直接驱动测点拟合核（控制点、张力、混合曲率、平滑先验、稳健加权、
   C0 折线、法向约束）。每次修改都会重新拟合并回灌左侧的约定检查与建议；失败会显示在视口下方，
   不会静默给出结果。

## 资料包与重建脚本（入库内容）

资料包是**真实入库的文件**，位于 `data/fabrication/*.json`，由脚本生成，可被测点拟合直接加载：

```bash
npm run gen:fabrication        # 重新生成四个资料包 + manifest.json
npm run reconstruct:fabrication -- analytic-refined   # 载入、拟合、校验并打印执行证据
npm run reconstruct:fabrication -- section-refined --allow-fail
```

`reconstruct:fabrication` 在任一约定不通过时以非零码退出，所以它既是重建脚本也是可执行证据：
资料包一旦偏离声明就无法静默通过。

每个资料包内含：自制测点（含 `reliability`：σ、标签置信度、离群标注）、拟合配方 `recipe`、
独立样板 `fixture`、真值曲面规格与网格 `truth`、以及生成参数与过程记录 `provenance`。

### 约定与角色分离

- **拟合者**只拿到 `observations` 与 `recipe`：`fitAdapter` 在拟合前剥离 `reliability`
  并从不读取 `truth` / `fixture`。真值控制点不会被当作解直接使用。
- **装配者**只读拟合曲面与独立样板：`assemble()` 计算扣合率与逐段间隙，从不读真值与原始测点。
- **校验**才同时读取真值、测点覆盖与离群标注，用于解释特征为何丢失。

### 关键结论（由测试固定）

`section-refined` 的**拟合残差更低**（约 0.474 mm vs `analytic-refined` 0.492 mm），
但其**样板扣合率低得多**（约 65% vs 99%），棱边建议也不同（`method-review` vs `none`）。
这说明：残差相近时，无法用残差决定哪段棱边还需补测，**实际样板扣合率**才能。
这也正是区分"解析曲面后采样"与"标定截面拼装真值"的边界条件。
